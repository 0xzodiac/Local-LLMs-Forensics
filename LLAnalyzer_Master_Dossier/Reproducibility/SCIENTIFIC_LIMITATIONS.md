# Consolidated scientific limitations

## Historical implementation provenance

The original source identifier `388d39f3e` is unresolved; the historical
executable and startup manifest are absent. Retained run JSON and reports can
support bounded observations and arithmetic, but not exact binary attribution.
Place the qualification in Methodology and Open Science.

## Prompt-patch provenance and causality

The retained historical prompt patch is malformed. Remediation 2's pinned
implementation is new engineering evidence and has no model-backed scientific
run. State the aggregate baseline/sanitised difference descriptively; do not
claim a fully proven causal historical patch effect.

## Timing data

The cached/uncached TTFT vectors, request-order manifest, and AUC script are not
available. Preserve AUC=1.000 as a reported evaluated-condition result and do
not claim independent recomputation, robust causal timing inference, or WAN
generalization.

## Forensic access

Memory acquisition uses the authorized F path, including a documented
parent-child relationship and Linux permission checks. It establishes
conditional recoverability. It does not establish arbitrary same-UID access or
an unprivileged co-resident exploit.

## Tenant identities

Separate valid API keys are authentication inputs. The saved-slot experiment
does not independently establish distinct security principals or resource
ownership. Describe a cross-credential shared-state hazard, not an absolute
tenant-isolation verdict.

## Application scope

LM Studio persistence is configuration-specific, and Ollama monitoring is a
bounded negative observation over captured channels and sessions. Neither
supports a universal wrapper-default claim.

## Negative results

RQ1's no-failure observation is limited to its explored corpus, campaign,
instrumentation, and historical configuration. Ollama's no-canary observation
is limited to monitored sessions and channels. Neither becomes a proof of
absence outside those conditions.

## Cross-machine replication

The Ikram rerun is author-reported collaborative evidence. Server-side records
were not locally inspected, so exact configuration and per-experiment numeric
agreement remain unverified in this package. The statement should be recorded,
not omitted and not overstated.
