## How to use in the manuscript

Include one concise reproducibility statement: a complete collaborator rerun was
reported to match the original framework. Put exact numerical values in the
main tables only when they are attributed to the retained primary records or
independently recomputed local artifacts. Use the Supplement to explain the
two-level evidence record. Do not make recovery of the server bundle a
prerequisite to preparing the rewrite.
