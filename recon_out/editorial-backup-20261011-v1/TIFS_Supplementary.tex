This document contains the extended experimental methodology and statistical
analysis for the associated IEEE T-IFS manuscript. The main manuscript is
independently understandable and retains the threat assumptions, core
configuration, sample sizes, success criteria, primary quantitative results,
and principal limitations. Sections S1--S2 provide the detailed environment,
workload, instrumentation, reproducibility, and analysis specifications used
to obtain those results.
